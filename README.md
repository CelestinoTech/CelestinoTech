# 🧠 Sobre mim

Sou Gabriel Celestino, estudante de Ciência da Computação e integrante do time de Plataforma do Santander. Tenho como objetivo atuar profissionalmente com desenvolvimento de software, com foco na linguagem Java, área que venho estudando, realizando projetos e aprofundando de forma contínua.

Sou apaixonado por inovação e meu principal objetivo é consolidar minha transição para a área de Tecnologia. Iniciei minha trajetória na Superbom, evoluindo rapidamente de Estagiário a Assistente de TI. Lá, otimizei dashboards no Power BI utilizando SQL Server e implementei servidores de rede estruturados com Ubuntu e Active Directory.

Atualmente, atuo no Santander Brasil na área de Canais Internos, com foco na Experiência do Usuário (UX). Trabalho mapeando aplicações, documentando regras de negócio e aprimorando fluxos da plataforma. Essa experiência me proporcionou uma visão sistêmica que conecta tecnologia, negócio e experiência do usuário.

Aqui no GitHub compartilho projetos, estudos e experiências que fazem parte da minha evolução na área de Tecnologia.
